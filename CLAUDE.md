# CLAUDE.md

Полное описание проекта, структура, команды и правила — в **AGENTS.md**. Прочитайте его перед работой:

@AGENTS.md

## Обязательно при каждом изменении

1. **Обновляйте AGENTS.md в том же коммите**, если поменялись архитектура, структура папок, команды моста, сборка/CI, конвенции или поведение приложения. Добавьте строку в «Журнал изменений».
2. Обновляйте этот файл, если меняются правила работы для Claude.
3. Если меняется контракт моста — синхронно правьте `web/src/bridge/contract.ts`, Kotlin-модуль, `docs/bridge.md` и `web/src/bridge/mock.ts`.
4. Если меняется API модов — `web/src/mods/api.ts` и `docs/mods.md`.

## Перед пушем

```bash
cd web && npm run lint && npm run typecheck && npm test && npm run build
cd ../android && ./gradlew :app:assembleDebug   # если трогали Kotlin или ресурсы
```

Если меняли интерфейс, пересоберите скриншоты: `cd web && npm run screenshots`.

## Коротко о правилах

* Только токены дизайн-системы Graphite, анимировать только transform/opacity.
* В effect читайте сигналы до любых условий с коротким замыканием.
* Платформа — только через `web/src/bridge/bridge.ts`.
* Версия NewPipeExtractor — только в `android/gradle/libs.versions.toml`.
* Без аналитики. Никаких секретов в репозитории: ключи подписи, API-ключи нейросети, логины/пароли прокси — только у пользователя (ссылки `youmusic://` отдаются в чат, не в код).
* Все HTTP-запросы — через `Http.client`/`Http.callFactory` (иначе не работают прокси).
* Тексты UI — на русском.
* Ответы пользователю — на русском.
